Updates

Update from WHM in two clicks. Every update is checked against the project's signing key before it changes anything, and your sites keep being served.

Check now and Update now

Open WHM → Plugins → OLS-cPanel → Updates. The page checks the project's GitHub releases (at most every 15 minutes) and shows Version X is available when a newer release exists. Check now asks again at once. Update now installs the new release after you confirm.

The update runs as a job you can follow on the page and in Jobs. A failure is shown with the installer's last lines, and nothing is changed when a check fails.

What an update checks

  1. The installer and its signature of exactly that release are downloaded over HTTPS into a private temporary directory.
  2. The signature is checked against the release key shipped inside the installed product, in a separate temporary keyring. A release that is not newer, a signature by any other key or a changed installer is refused.
  3. The verified installer checks the release manifest and every package exactly as for an installation, and upgrades the packages. It never downgrades anything.

The product then applies the upgrade by itself within a minute: it restarts its own services, refreshes the WHM and cPanel plugins, reloads OpenLiteSpeed gracefully when its binary changed, and restarts only the PHP processes whose settings changed. Your sites keep being served.

For each installed package the page shows Signed (it carries the project's rpm signature) or Verified release (the installer checked exactly this build against the signed release).

Signed releases

Releases are signed with the project's release key.

Fingerprint118DFA42F66A585D176C0B5148E26833CB82EAD1
TypeRSA 4096, valid until 2029-10-27
Key serverkeyserver.ubuntu.com, fetched by the fingerprint above
In the repositorybuild/release/ols-cpanel-release-key.asc

The installer carries this key and trusts nothing else; a release signed by any other key is refused. The packages are rpm-signed with the same key.

From the command line

Run the one command of the newer release from its release notes, exactly as for the installation. On an installed server it upgrades the packages, changes nothing else and does not ask for a switch again. Running the command for the release that is already installed says so and changes nothing.
