WHM plugin tour

The administrator's side. Open it in WHM under Plugins → OLS-cPanel. It is available to root only. Every screenshot is an example; click one to enlarge it.

Overview

The state of the web server at a glance: what serves ports 80 and 443, the deployment profile (hybrid when Apache stays on standby), the active configuration, pending cPanel changes and a short health list in plain words.

Switch center

Move the server from Apache to OpenLiteSpeed and back, with a reviewed plan and automatic recovery. This is where you switch if you did not do it during the install.

Compatibility

Every finding across all accounts: what blocks a site from OpenLiteSpeed and why. Sites OpenLiteSpeed cannot reproduce exactly are kept on Apache automatically.

Accounts & domains

Every domain with its engine, PHP handler, certificate and status, so you can see at once which sites OpenLiteSpeed serves.

Generations

Compiled and validated configurations. The active one serves traffic; earlier ones are kept for reference.

Jobs

Every product job, one at a time. You can follow a job even after closing the page.

Job detail

Open a job to see its timeline step by step, with the result of each step.

Page cache

The LiteSpeed page cache per site: how much is stored, and purge for one site, one account or the whole server.

PHP

EA4 PHP versions with OPcache, the PHP worker processes of every account, and the limits in force.

Object cache

The automatic object cache switch and the accounts that have a private Valkey cache. Your decision for an account always wins. See Object cache.

Requests

Messages that accounts sent to you from their control panel (the Contact my host page).

Diagnostics

How the server is doing, in plain words, and the details behind it.

Activity

Who did what on this server through OLS-cPanel, newest first: switches, returns, cache and PHP actions, setting changes.

Notifications

Get a message when something needs your attention. It stays off until you add an address or a webhook.

Maintenance windows

Run the switch to OpenLiteSpeed or the return to Apache at a time you choose.

Updates

Installed and available versions and whether this server is supported. Check now looks for a new release and Update now installs it. See Updates.

Support

Create a diagnostics archive to attach to a support request.

Light and dark

The interface follows your system's light or dark preference and has its own switch in the header.
