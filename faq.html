OpenLiteSpeed for cPanel: frequently asked questions

Is there a free LiteSpeed for cPanel?

Yes. OLS-cPanel-WHM runs OpenLiteSpeed, LiteSpeed Technologies' free open-source web server, on cPanel & WHM at no cost under GPLv3. It brings the LiteSpeed page cache (LSCache), HTTP/3, a per-account object cache, and WHM and cPanel plugins. Separately, LiteSpeed Technologies sells LiteSpeed Web Server (Enterprise), which works with cPanel; its product page lists a "Free Starter" tier with "1 Domain, 2GB limit".

Is OLS-cPanel-WHM made by LiteSpeed or cPanel?

No. OLS-cPanel-WHM is an independent open-source project maintained by 2T Development on GitHub under GPLv3, and it is not affiliated with or endorsed by LiteSpeed Technologies or cPanel, L.L.C. It uses OpenLiteSpeed, LiteSpeed Technologies' free GPLv3 web server, not the commercial LiteSpeed Enterprise.

Do I need to leave cPanel to use OpenLiteSpeed?

No. With OLS-cPanel-WHM, cPanel & WHM stay in place and keep managing accounts, domains, certificates and PHP versions. OLS-cPanel-WHM replaces Apache as the web server for the sites, and the server can be returned to Apache at any time.

Can I use LSCache on cPanel without LiteSpeed Enterprise?

Yes, with OLS-cPanel-WHM. LiteSpeed Cache for WordPress needs a LiteSpeed server, and OpenLiteSpeed is one of the servers LiteSpeed lists for it. OLS-cPanel-WHM puts OpenLiteSpeed in front of cPanel accounts, so the LiteSpeed Cache plugins for WordPress, Joomla, Drupal and Laravel can serve cached pages. Site owners clear the page cache with the Clear cache icon in cPanel. LiteSpeed's LSCache for WordPress FAQ notes that some features, such as ESI, may not be supported on OpenLiteSpeed.

Does OLS-cPanel-WHM enable HTTP/3 on cPanel?

Yes. OLS-cPanel-WHM includes HTTP/3 through OpenLiteSpeed, and it is applied automatically from cPanel's own settings. The switch plan the installer shows includes an HTTP/3 line with its firewall setting. Site owners can run the Speed check in the cPanel plugin to confirm that a site is compressed, cached, offered over the fastest connection and has a valid certificate.

Which systems does OLS-cPanel-WHM support?

The current release of OLS-cPanel-WHM supports AlmaLinux 9 on x86_64 with a licensed, working cPanel & WHM. The release notes list the exact operating system and cPanel versions each release was tested on, and only those are supported.

Does OLS-cPanel-WHM work on CloudLinux or Rocky Linux?

Not yet. The current release of OLS-cPanel-WHM supports AlmaLinux 9 only. Rocky Linux, CloudLinux and release 8 systems are planned for later releases, and the installer refuses an unsupported system before changing anything.

Does OLS-cPanel-WHM install or license cPanel?

No. OLS-cPanel-WHM does not install or license cPanel; it works on a server that already runs a licensed cPanel & WHM.

Will my sites go offline while I install OLS-cPanel-WHM?

No. The OLS-cPanel-WHM installer prepares the server while Apache keeps serving. The switch happens only after you approve the plan, and every site is checked afterwards. If a check fails, the server returns to Apache automatically.

Can I install OLS-cPanel-WHM now and switch later?

Yes. Add --prepare-only to the installer call, or decline at the approval. Switch later from WHM → Plugins → OLS-cPanel → Switch center, or schedule it in a maintenance window.

Do .htaccess changes apply without a restart?

Yes. The product checks the sites' .htaccess files every minute and applies a change by itself with a graceful reload that keeps connections open; nobody has to restart anything. Apache reads .htaccess on every request, so there a change is visible at once; here it takes up to about a minute. A site whose rules OpenLiteSpeed cannot reproduce exactly stays on Apache behind OpenLiteSpeed, so it keeps working.

What happens to sites with unusual .htaccess rules?

A site whose .htaccess rules OpenLiteSpeed cannot reproduce exactly stays on Apache, which runs in standby behind OpenLiteSpeed. Site owners see this in the .htaccess advisor of the cPanel plugin, and nothing needs to be done.

Does it install the LiteSpeed Cache plugin?

No. It never changes your sites' code or plugins. The page cache works with LiteSpeed's own free plugins (LiteSpeed Cache for WordPress and the LSCache modules for Joomla, Drupal and Laravel), which the site owner installs as usual. When LiteSpeed Cache for WordPress is active, the product connects it to the account's object cache by itself.

Do my customers have to set up the object cache?

Not for WordPress with LiteSpeed Cache: the OLS-cPanel-WHM object cache is configured automatically. Other applications need the values entered once. See Object cache.

Which OpenLiteSpeed version does OLS-cPanel-WHM use?

As of release 0.2.14, OLS-cPanel-WHM bundles OpenLiteSpeed built from the upstream 1.9.3 source with the project's own patches. Since release 0.2.13 it also includes the PHP socket fix that upstream made in OpenLiteSpeed 1.9.4.

Does OLS-cPanel-WHM work with ModSecurity and the OWASP Core Rule Set?

Yes. Servers that use cPanel's OWASP Core Rule Set (WHM, ModSecurity Vendors) can be switched to OpenLiteSpeed: the rule set runs there and, according to the project's changelog, blocks the same attacks as under Apache. ModSecurity is applied automatically from cPanel's own settings.

How do I update OLS-cPanel-WHM?

In WHM, open Plugins → OLS-cPanel → Updates, press Check now and then Update now. See Updates.

Do I have to do anything when I add accounts or domains?

No. Changes in cPanel (accounts, domains, certificates, PHP versions, suspensions) apply by themselves.

How do I know an OLS-cPanel-WHM release is genuine?

OLS-cPanel-WHM releases are signed. The installer verifies the signature and every package digest before it changes anything. The key fingerprint is 118DFA42F66A585D176C0B5148E26833CB82EAD1, and the stricter install command fetches the key from keyserver.ubuntu.com by that fingerprint.

Can I go back to Apache after installing OLS-cPanel-WHM?

Yes, at any time. See Going back. Uninstalling returns the server to Apache first and then removes what the product added. The ea-php*-php-opcache packages and the system journal stay. With --keep-backups the backups are kept, and with --keep-packages the product packages stay installed and the dnf remove command is printed instead.

Where do I report a problem with OLS-cPanel-WHM?

Open an issue on GitHub. For a security problem, do not open a public issue; use the private vulnerability report form.

What is the license of OLS-cPanel-WHM?

GNU General Public License v3. OpenLiteSpeed is GPLv3 as well, and the PHP redis extension package is under the PHP License 3.01.
