Frequently asked questions

Which systems are supported?

AlmaLinux 9 on x86_64 with a licensed, working cPanel & WHM. This first public release supports AlmaLinux 9 only. The installer refuses an unsupported system before changing anything.

Does it install or license cPanel?

No. It works on a server that already runs a licensed cPanel & WHM.

Will my sites go offline during the install?

No. The installer prepares the server while Apache keeps serving. The switch happens only after you approve the plan, and every site is checked afterwards. If a check fails, the server returns to Apache automatically.

Can I install it now and switch later?

Yes. Add --prepare-only to the installer call, or decline at the approval. Switch later from WHM → Plugins → OLS-cPanel → Switch center, or schedule it in a maintenance window.

What about sites that use unusual .htaccess rules?

Sites OpenLiteSpeed cannot reproduce exactly stay on Apache, which runs in standby behind OpenLiteSpeed. Site owners see this in the .htaccess advisor and nothing needs to be done.

Do I have to do anything when I add accounts or domains?

No. Changes in cPanel (accounts, domains, certificates, PHP versions, suspensions) apply by themselves.

Do my customers have to set up the object cache?

Not for WordPress with LiteSpeed Cache: it is configured automatically. Other applications need the values entered once. See Object cache.

How do I update?

In WHM, open Plugins → OLS-cPanel → Updates, press Check now and then Update now. See Updates.

How do I know a release is genuine?

Releases are signed. The installer verifies the signature and every package digest before it changes anything. The key fingerprint is 118DFA42F66A585D176C0B5148E26833CB82EAD1, and the stricter install command fetches the key from keyserver.ubuntu.com by that fingerprint.

Can I go back to Apache?

Yes, at any time. See Going back. Uninstalling returns the server to Apache first and then removes everything the product added; nothing of it stays on the server.

Where do I report a problem?

Open an issue on GitHub. For a security problem, do not open a public issue; use the private vulnerability report form.

What is the license?
