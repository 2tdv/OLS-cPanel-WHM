Going back to Apache and uninstalling

You can return to Apache at any time. The product stays installed so you can switch again, or you can remove it completely.

Return to Apache

From WHM, use the Switch center. From the command line, as root:

/usr/local/ols-cpanel/bin/ols-cpanel apache-return --prepare

This checks that Apache can be rebuilt from cPanel's current configuration (not from an old copy taken on the day of installation) and shows a plan. Then run the second command with the plan id the first one printed:

/usr/local/ols-cpanel/bin/ols-cpanel apache-return --execute --plan=<plan id shown by the previous command>

It stops OpenLiteSpeed, gives ports 80 and 443 back to Apache, removes the product's Apache port changes, include file and firewall rule if they were used, and checks every site.

Uninstall

/usr/local/ols-cpanel/bin/ols-cpanel uninstall --dry-run
/usr/local/ols-cpanel/bin/ols-cpanel uninstall

The dry run lists every action and changes nothing. The real run first returns the server to Apache if OpenLiteSpeed is still serving, and verifies that Apache serves ports 80 and 443. Only then does it remove what the product added.

Removed: the cPanel hooks, the WHM and cPanel plugins and every product service and timer; LiteSpeed Cache's object cache setting in WordPress sites where the product had switched it on (a site whose owner changed it is never touched); the per-account object cache instances and each account's ~/.ols-objcache; the product's state directory, including the cutover backups (add --keep-backups to keep them); the INI files the product wrote; the recommended EasyApache profile file it added; the project key and the installer's report; the three product packages; and then what they leave behind: OpenLiteSpeed's runtime files in /usr/local/lsws, the olscpanel system user, and Valkey with its user when it came with the product.

Kept: the OPcache packages, the system journal, and everything the product did not create. Nothing of the product stays on the server. It never removes your sites' files, cPanel's certificates or changes made by an administrator. It can be run again if it is interrupted.

Do not remove the packages with dnf remove while OpenLiteSpeed is serving: that would remove the web server without giving the ports back to Apache. Use the uninstall command.
